# Cozy Solitaire 3.0 — Skærmkatalog (til design)

| Skærm | Primær oplevelse | Design- og funktionelle krav |
|---|---|---|
| Velkomst / onboarding | Varm intro og spilleridentitet | Elegant logo, kort intro, sprogvalg, avatar |
| Min have | Fordybende fuldskærmsillustration | Zoom, pan, placér/tryk på objekter; fast, let HUD |
| Kabale | Selve kortspillet i fokus | Store læsbare kort, drag/drop, undo/hint, få handlingsknapper |
| Minispil | Enkel adgang til optjening | Tydelig belønning, antal træk, hurtig retur |
| Opgaver | Historie og progression | Millie/Marmalade, få åbne quests, synlig fremdrift |
| Byg og dekorér | Læg dekorationer i haven | Forhåndsvisning, placer/roter, optjeningspris |
| Hovedmenu | Enkel navigation | Overskuelige kategorier uden overflødige handlinger |
| Indstillinger | Profil og tilpasning | Reelle unikke avatarer, sprog, grafik, lyd, spilregler |
| Dialoger og belønninger | Beslutninger og feedback | Tekst og knapgrafik må aldrig overlappe |

Alle skærme skal godkendes som **grafiske skitser** i både dansk/engelsk, før kode skrives.
